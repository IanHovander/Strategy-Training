# FRC Strategy Lab

An interactive, self-paced course for teaching FRC strategy and decision-making under uncertainty.

## Website
After GitHub Pages is enabled, the public website will be:

https://ianhovander.github.io/Strategy-Training/

## Publish (one-time setup)
1. Open [Settings → Pages](https://github.com/IanHovander/Strategy-Training/settings/pages).
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then **Save**.

GitHub Pages will publish `index.html` at the URL above. Subsequent changes to the `main` branch are published automatically at the same address.

## Develop
The entire working website is in `index.html`, including styling, scripts, and the first ten Risk & Consistency investigations. No build step, dependencies, or external server are required. Open via a local static web server if testing browser functionality.

## Student progress
Lesson completion is saved in the student's browser using local storage where supported. There is currently no account system, central class dashboard, or progress syncing across devices.

## Educational model
The scenarios are abstract teaching simulations, not any particular FRC game. Ties are tracked separately. Calculations and results depend on the stated assumptions.
